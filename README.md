# Motive-Language_Localization

## 简介

本仓库用于存放 Motive 的 lang 语言文件。

## 贡献规范

- **格式**：所有语言文件统一使用 **JSON** 格式，并保持与现有语言文件一致的键名与结构。
- **提交方式**：所有修改必须通过 **Pull Request** 提交，请勿直接推送。
- **内容规范**：请确保译文不违反规则。
- **疑问反馈**：对任何译本存在疑惑，请提交 [Issues](https://github.com/Motive-Dev-Studio/Motive-Language_Localization/issues)。

## About

This repository stores Motive's lang files.

- **Format**: all language files use a unified **JSON** format.
- **Contributions**: submit all changes via **Pull Requests**.
- **Content**: make sure translations do not violate the rules.
- **Questions**: if you have doubts about any translation, please open an Issue.
